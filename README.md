# PRIME / Твои скины. Твои правила.

Новый статический лендинг Prime Market для GitHub Pages. Визуальная концепция создана с нуля: тёплая светлая основа, оранжевый акцент, крупная типографика, тёмный интерактивный образец торгового правила. Старые HTML, CSS и JavaScript не используются.

## Запуск

Открой `index.html` в браузере или запусти из корня проекта:

```sh
python -m http.server 8080
```

Затем открой `http://localhost:8080`. Не нужны Node.js, npm, сборка, сервер приложений или переменные окружения. Все ресурсы локальные. Шрифты системные, внешних библиотек нет.

## GitHub Pages

1. Проверь изменения и слей ветку редизайна в `main`.
2. В репозитории открой **Settings > Pages > Build and deployment**.
3. Выбери **Deploy from a branch**, ветку **main**, каталог **/(root)** и нажми **Save**.
4. Дождись успешной публикации в Actions / Pages. Если такой источник уже настроен, повторная настройка не нужна.

`.nojekyll` добавлен. Относительные пути `./style.css`, `./app.js`, `./favicon.svg` подходят и для пути `/Prime-Bot-Site/`, и для корня отдельного домена.

Существующий `CNAME` со значением `www.primemarket.skin` сохранён. DNS, настройки домена, HTTPS и источник публикации не менялись. CNAME сам по себе не настраивает домен: проверь его в Pages. Для публикации только на стандартном адресе GitHub отключи custom domain в Pages и удали CNAME.

Официальные инструкции: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что редактировать

- `index.html`: тексты, секции, ссылки и метаданные. Все основные кнопки ведут в существующий канал `https://t.me/primebot_news`.
- `style.css`: палитра в `:root`, типографика, компоненты, адаптивные стили и режим уменьшенного движения.
- `app.js`: мобильное меню и локальная симуляция. Рыночные сценарии находятся в объекте `scenarios`.
- `favicon.svg`: новый векторный знак PRIME.
- `tests/smoke.py`: проверка ассетов, структуры, вёрстки и поведения.

## Честные границы демо

Статус «в разработке» и канал взяты из исходного репозитория. Дата запуска, тарифы, реальная доступность бота и его серверная реализация не подтверждались. Возможности описаны как концепция; перед запуском их нужно сверить с продуктом.

В демо три вымышленных сценария: конкурент выставляет 1 280, 890 или 1 590 рублей. Правило выбирает цену на 1 рубль ниже конкурента. Если она ниже выбранного минимума, сохраняется предыдущая цена 1 480 рублей. Это иллюстрация принципа, не копия торгового алгоритма, не котировки и не прогноз прибыли.

Сайт не отправляет сделки, не запрашивает API-ключи, не хранит пользовательские данные и не содержит форм оплаты, аналитики или трекеров. GitHub и внешние сайты могут вести собственные технические журналы. Ссылка на канал не подписывает пользователя автоматически и не создаёт запись в листе ожидания.

Внешние ссылки сохранены, но доступность канала и реальный Pages-деплой не проверялись. Неподтверждённые счётчики сделок, uptime, доходности и таймер запуска не переносились.

## Проверки

Установи Python-пакет Playwright и его Chromium:

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/smoke.py
```

В среде с запретом браузерной навигации на localhost доступен вариант:

```sh
python tests/smoke.py --inline --report test-report.json
```

Он рендерит те же HTML/CSS/JS в памяти. Выдача реальных файлов по HTTP при этом проверяется отдельно. Итоги выполненного прогона см. в `QA.md`.

Не-JS версия сохраняет тексты, ссылки, навигацию и раскрывающиеся ответы. Контролы симуляции без JavaScript отключены, чтобы не имитировать работу. Мобильное меню поддерживает Escape, возврат фокуса и сброс при изменении ширины. Слайдер поддерживает клавиатуру, статусы объявляются через `aria-live`, учтён `prefers-reduced-motion`.
