# PRIME / Market Center

Тёмный визуальный лендинг для GitHub Pages. Палитра: обсидиан, титан, мятный акцент. Интерфейс адаптирован по предоставленному владельцем скриншоту программы.

## Запуск

Открой `index.html` в браузере. Либо из корня проекта:

```sh
python -m http.server 8080
```

Открой `http://localhost:8080`. Для самого сайта не нужны npm, сборка, сервер приложений, внешние шрифты или CDN. Все ресурсы локальные. HTML + CSS + JavaScript, примерно 68 КБ основных исходников до сжатия.

## Публикация

Сайт совместим с существующей публикацией из `main` / `/(root)`. `.nojekyll` и относительные пути сохранены. Существующий `CNAME` указывает на `www.primemarket.skin`; DNS и настройки домена не изменяются. После слияния в `main` проверяй `pages build and deployment` в Actions.

Если Pages ещё не настроен: Settings > Pages > Deploy from a branch > main > /(root).

## Что внутри

- `index.html`: короткие тексты, ссылки, SVG-иконки, адаптивный образ интерфейса.
- `style.css`: компоненты, брейкпоинты 320–1920 px, состояния, CSS-анимации.
- `app.js`: собственный небольшой 3D-рендерер, мобильное меню, полноэкранный просмотр интерфейса и настройки движения.
- `favicon.svg`: знак PRIME.
- `tests/smoke.py`: браузерные проверки.
- `QA.md`: результаты и границы выполненной проверки.

## 3D и движение

Буква P — экструдированная полигональная геометрия с фасками, внутренним отверстием, перспективной проекцией, освещёнными гранями и металлическими градиентами. Орбиты и спутники также рассчитываются в 3D. Рендер выполняется через Canvas 2D, без WebGL и библиотек. Это не вращаемая картинка.

Сцена реагирует на курсор; частота ограничена 30 кадрами/с, DPR ограничен 2. Рендер останавливается вне экрана и в скрытой вкладке. Кнопка паузы выключает движение; учитывается `prefers-reduced-motion`. При недоступном Canvas остаётся CSS-иллюстрация.

## Содержание и безопасность

Это публичный лендинг, а не авторизованный торговый кабинет. Показатели 162 / 20 / 0 / 0, события AWP и статус бота взяты из предоставленного скриншота и не обновляются с сервера. Элементы внутри изображения интерфейса не имитируют настоящую отправку команд; они семантически оформлены как изображение продукта. Настоящие интерактивные элементы — навигация, увеличение интерфейса, 3D-сцена и переключатель движения.

Нет ввода ключей, платежей, аналитических трекеров и запросов к торговому API. `localStorage` хранит только предпочтение движения. Основные ссылки ведут в существующий канал `https://t.me/primebot_news`; это не автоматическая подписка и не заявка на доступ. График и иллюстрации объясняют продукт, не прогнозируют доходность.

На публичной странице нет служебных обозначений о предварительной версии. Условия и доступность самого бота управляются отдельно от лендинга. Не добавляй API-ключи и секреты в этот репозиторий.

## Проверка

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/smoke.py
```

Для окружения, запрещающего браузерную навигацию на localhost:

```sh
python tests/smoke.py --inline --report report.json
```

Этот режим использует те же HTML/CSS/JS в памяти и отдельно проверяет HTTP-выдачу файлов. Он не подменяет проверку опубликованного домена. Для сравнения изменений используйте историю Git; старые версии остаются в коммитах.
