# PRIME / Рынок твой. Время тоже.

Лендинг и кликабельный Market Center на HTML, CSS и JavaScript. Без npm, сборки, сторонних библиотек, сетевых запросов из JavaScript и серверной части. Открывается как обычный `index.html`, публикуется из корня GitHub Pages.

## Что изменилось

Убраны декоративные подписи, нумерация сцен, повторяющиеся плашки и отдельная длинная схема Engine. Основное действие теперь «Попробовать PRIME». За ним не скриншот: пять разделов приложения с общим состоянием, встроенный и развёрнутый режимы. На мобильном навигация расположена снизу.

Исходный сайт был просмотрен по актуальному HTML репозитория и отрендеренным исходникам. Публичные страницы IBS Technology и Top Car прочитаны через веб-поиск: у них ясные действия «Обсудить проект» и «Рассчитать стоимость». Их живые анимации и внешний вид в удалённом браузере не проверены: навигация блокировалась средой. Чужие графические материалы не переносились. Палитра приложения, структура товаров, аналитики и настроек основаны на скриншотах владельца.

## Кликабельное приложение

- Обзор: сводка локального набора данных, события, переключатели, переход к товарам.
- Товары: поиск, сортировка, выбор предмета, смена цены, нижняя граница, шаг 0,01 / 0,05 / 0,50 ₽, история и переключатель автоцены предмета.
- Сделки: поиск, фильтр продаж/покупок, суммы и CSV выбранных строк.
- Аналитика: показатели вычисляются из четырёх сделок, график количества/сумм, периоды и журнал пользовательских действий.
- Настройки: имя, светлая/тёмная тема, переключатели, интервал, локальное уведомление и сброс с подтверждением.

Ссылки на разделы: `#app/overview`, `#app/products`, `#app/trades`, `#app/analytics`, `#app/settings`. Просмотр можно развернуть или закрыть по Escape. Данные не теряются между встроенным и полноэкранным режимами.

## Границы просмотра

Это интерактивная презентация, не рабочий торговый кабинет. Одно пояснение находится в меню «В браузере». Аккаунт, торговая площадка и Telegram не подключаются; API-ключи, пароли и платежи не запрашиваются. Автоцена и интервал изменяют настройки просмотра, но не запускают торговые операции. Обновление перечитывает интерфейс, а не рынок.

Названия и исходные суммы взяты из скриншотов владельца. Для знакомства с интерфейсом собраны шесть предметов; это не полный инвентарь. Минимальные цены заданы для локальных сценариев. Четыре исходные продажи датированы 22 сентября 2026. Периоды аналитики заканчиваются этой датой, поэтому три периода дают одинаковый результат при этих четырёх сделках. Рекламные графики вне приложения декоративны и не являются котировками.

Изменения сохраняются в `sessionStorage` этой вкладки. Повреждённое хранилище заменяется исходным состоянием; при недоступном хранилище приложение работает в памяти. Кнопка сброса возвращает начальные значения. Денежные значения внутри приложения хранятся в целых копейках, пользовательский текст экранируется. SVG-силуэт оружия условный, не официальный рендер скина.

## Файлы

`index.html` - страница и контейнеры диалогов.
`style.css` - композиция лендинга и адаптивность.
`script.js` - навигация, полноэкранный просмотр, вкладки и управление анимациями.
`assets/workspace.js` - локальные данные и приложение.
`assets/workspace.css` - интерфейс и темы приложения.
`assets/prime-scene.js` - ранее созданная объёмная геометрия и Canvas-рендерер.
`tests/smoke.py` - функциональные браузерные проверки.

Шрифты системные. Все поставляемые ресурсы локальны. Контакты ведут в существующий канал `https://t.me/primebot_news`, а не на неизвестный адрес бота или скачивания программы.

## GitHub Pages

Существующие `CNAME` и `.nojekyll` сохранены. Источник Pages, HTTPS, DNS и сторонние сервисы не изменяются. Для существующего режима публикации из `main` достаточно объединить обновление. Все пути относительные.

Локальный запуск: `python -m http.server 8080`.

## Проверка

Установить Playwright для тестов: `python -m pip install playwright`, затем `python -m playwright install chromium`.

Обычный прогон по HTTP: `python tests/smoke.py --report test-report.json`.

Для среды с запретом браузерной навигации: `python tests/smoke.py --inline --chromium /usr/bin/chromium --report test-report.json`.

Подробности и ограничения последнего выполненного прогона в `QA.md`. В inline-режиме браузер получает те же CSS/JS в памяти, а сохранение проверяется через подстановку API sessionStorage; это не проверка хранилища настоящего домена. HTTP-выдача файлов проверяется отдельно.
