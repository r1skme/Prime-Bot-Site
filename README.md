# PRIME / Рынок твой. Время тоже.

Статический лендинг PRIME Market Center. Пять сцен и полноэкранный финал. HTML, CSS и обычные скрипты, без сборщика, npm, CDN и внешних запросов из кода страницы.

## Запуск

Открой `index.html` в браузере. Для локального HTTP: `python -m http.server 8080`.

GitHub Pages: существующая публикация из `main` / корня. `CNAME` со значением `www.primemarket.skin` сохранён без изменения. DNS, настройки Pages и HTTPS не редактируются кодом сайта. `.nojekyll` сохранён. Все ресурсы подключаются относительно текущего каталога.

## Структура

- `index.html`: содержание, ссылки и воспроизведение экрана приложения.
- `style.css`: оформление, адаптивность 320–1920 px, состояния и движение.
- `script.js`: меню, вкладки, диалог, последовательность сигнала, scroll choreography, пауза.
- `assets/prime-scene.js`: собственный рендерер объёмной геометрии: экструзия P с фасками, тороидальная поверхность, перспектива, нормали и сортировка по глубине. Рендер в Canvas 2D, не WebGL и не вращение плоской картинки. Нет зависимостей.
- `assets/prime-mark.svg`: статический векторный резервный вариант.
- `assets/favicon.svg`: значок сайта.
- `tests/smoke.py`: проверки в Chromium через Playwright, не зависимость сайта.

## Дизайн

Пять сцен: крупный 3D-знак / Market Center / цепочка рынок–правила–уведомление / три переключаемые функции / Telegram. Финал возвращает знак PRIME.

Основа — предоставленный владельцем скриншот Market Center. От описанного в ТЗ Radian взят принцип центрального объекта и перехода при прокрутке; от описания Refive — тёмная среда и направленный металлический свет. Публичные страницы открыты инструментом веб-чтения, но непосредственный просмотр этих сайтов в браузере среды блокируется. Не заявляется точное воспроизведение их анимаций.

Шрифтовые файлы в проект не включены: текущая типографика использует Arial / Helvetica / системный sans-serif и Courier New / monospace. Это отличие от пункта ТЗ о локально поставляемых шрифтах. Внешняя загрузка шрифтов не требуется.

## Данные и взаимодействия

162 активных товара, 20 продаж и строки событий взяты из предоставленного скриншота. На странице это экран приложения от 22.09, а не подключение к аккаунту или текущая статистика сервиса. Схематичные линии рынка не являются котировками. Кнопка «Проследить сигнал» анимирует локальную схему; она не отправляет реальное уведомление.

Все основные CTA ведут в уже использовавшийся канал `https://t.me/primebot_news`. Сайт не подписывает посетителя автоматически, не принимает API-ключи, не выполняет сделки, не хранит личные данные и не содержит форм оплаты или аналитики. Внешние сервисы и хостинг могут вести собственные журналы.

## Проверка

`python -m pip install playwright` и `python -m playwright install chromium` нужны только для запуска проверок. Затем `python tests/smoke.py`. Для среды, запрещающей браузерную навигацию на localhost: `python tests/smoke.py --inline --report report.json --screenshots screenshots`.

При `--inline` браузер получает те же HTML/CSS/JS в памяти; HTTP-выдача каждого файла проверяется отдельно. Область выполненной проверки описана в `QA.md`.
