# PRIME / проверка тёмного лендинга

22 сентября 2026. Chromium 144.0.7559.96. **46/46 проверок пройдено.**

Команда: `python tests/smoke.py --inline --report report.json`.

Проверено:

- HTTP-выдача HTML, CSS, JS, favicon, `.nojekyll`; относительные пути для Pages.
- Один H1, русский язык, существующие якоря, безопасные внешние ссылки.
- Отсутствие служебных подписей на странице, полей оплаты и API-ключей.
- Рендер 3D-сцены, изменение кадров, пауза, возобновление, остановка вне экрана.
- Отсутствие горизонтальной прокрутки на 320, 360, 375, 390, 430, 620, 700, 701, 768, 900, 1024, 1280, 1440 и 1920 px.
- Мобильное меню: открытие, фокус, Escape, переход по ссылке, изменение ширины.
- Диалог: открытие, уникальные ID, удержание фокуса, Escape, возврат фокуса, удаление копии и разблокировка прокрутки.
- Reduced motion, отсутствие JS, отсутствие Canvas.
- Отсутствие JavaScript runtime errors.

Дополнительно: `node --check app.js`; просмотр настольного и мобильного скриншотов.

Ограничения: окружение блокирует браузерный доступ к localhost. Поэтому использованы те же исходники, встроенные в страницу в памяти; HTTP-ассеты проверены отдельным клиентом. Это не end-to-end проверка опубликованного Pages. Safari, Firefox, реальный сервер бота, торговые операции и доступность Telegram-канала не проверялись. Полный аудит WCAG/Lighthouse не выполнялся.
