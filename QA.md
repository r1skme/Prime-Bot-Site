# Проверка PRIME / Interactive

22 сентября 2026. Chromium 144.0.7559.96.

Команда:
`python tests/smoke.py --inline --chromium /usr/bin/chromium --report test-report.json`

Результат: **119 / 119 проверок пройдено**.

- Десять ресурсов проверены по HTTP с побайтовым сравнением.
- 15 ширин: 320, 360, 375, 390, 430, 640, 768, 820, 900, 1024, 1100, 1280, 1440, 1600, 1920 px. На каждой проверены лендинг и все пять разделов развёрнутого приложения. Нет горизонтального переполнения страницы и рабочей области; широкая таблица сделок прокручивается внутри своего контейнера.
- Поиск, пустое состояние, сортировка и выбор товара; восемь недопустимых цен; ввод с запятой; минимум; шаг в копейках; обновление истории и журнала; конечные координаты графика.
- Фильтры сделок, содержимое CSV, расчёт оборота и полученных сумм, периоды и метрики графика.
- Редактирование профиля, экранирование HTML, тема, уведомления, интервал, отмена и подтверждение сброса.
- Переход между встроенным и развёрнутым интерфейсом, Escape, блокировка фона и возврат фокуса; клавиатурные вкладки и мобильное меню.
- Сохранение и восстановление через подставленный API sessionStorage, обработка повреждённого значения.
- 3D работает, ставится на паузу, останавливается за пределами экрана и за развёрнутым приложением. Учитывается reduced motion. Есть SVG при недоступном Canvas и базовый контент без JavaScript.
- Нет JavaScript runtime errors в проверенных сценариях. Проверен синтаксис трёх JS-файлов через `node --check`.

Просмотрены настольные и мобильные скриншоты лендинга и интерфейса. Проверки в Chromium используют исходники в памяти: среда блокирует навигацию браузера к внешним адресам и localhost. Это НЕ проверка опубликованного домена. Для inline-проверки sessionStorage использован API-совместимый объект; настоящий storage-домен не проверен. Не проверялись Safari, Firefox, физические устройства, реальные аккаунты и торговые операции. Полный WCAG/Lighthouse-аудит не выполнялся. Успех GitHub Pages следует проверять отдельно по результату deployment.
