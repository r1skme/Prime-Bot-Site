# Проверка редизайна PRIME

Дата: 22 сентября 2026. Chromium 144.0.7559.96. Результат: **75/75 проверок пройдено**.

Команда: `python tests/smoke.py --inline --report test-report.json`.

- HTTP-выдача пяти ассетов: HTML, CSS, JS, SVG, `.nojekyll`.
- Проверка относительных путей для `/Prime-Bot-Site/`.
- Ширины 320, 360, 390, 620, 768, 860, 1024, 1280, 1440, 1920 px: без горизонтальной прокрутки.
- Один H1, язык ru, существующие якоря, безопасные атрибуты внешних ссылок.
- 36 сочетаний: три сценария и 12 значений минимума. Цена всегда соответствует правилу и не ниже лимита.
- Единственный активный сценарий, клавиатурные Home / End / ArrowRight.
- FAQ: открывание и закрывание с клавиатуры.
- Меню: открывание, закрывание по Escape, возврат фокуса, закрывание по ссылке, сброс при переходе на desktop.
- Нет JavaScript runtime errors.
- `prefers-reduced-motion`: плавная прокрутка отключена.
- Без JS: контент, навигация и FAQ видны; демо-контролы отключены.
- Дополнительно: `node --check app.js` пройден, настольные и мобильные скриншоты просмотрены.

Ограничения: браузер этой среды блокирует навигацию на локальные URL. Поэтому браузерные проверки выполнены с теми же исходниками, встроенными в страницу в памяти; HTTP-ассеты проверялись отдельным клиентом. Это не проверка реального развёртывания на GitHub Pages. Firefox, Safari, доступность внешнего Telegram-канала, сервер бота и реальные операции не тестировались. Полный аудит WCAG / Lighthouse не выполнялся.
